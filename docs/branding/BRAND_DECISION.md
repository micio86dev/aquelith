**Status: PENDING USER APPROVAL**

Date: 2026-11-05. Source: `docs/branding/NAMING_RESEARCH.md`. Not legal clearance.

## Summary of findings

- No exact or near-exact AQELITH / AQUELITH usage found on GitHub, npm, PyPI, crates.io, RubyGems, Go, Homebrew, Maven, or web search.
- GitHub handles `aqelith`, `aquelith` unclaimed (404). Matching .com/.net/.dev/.app/.org/.io/.ai return RDAP not found (indication only).
- Look-alikes exist and are active: Aqualith (org, synth, game, perfume), Aquilith (org, domain), Aquolith (domain registered 2026-05), Aquelit/Aquelity (orgs). "Aqu-" software marks exist (e.g. AQUILON, live US Class 9).
- Trademark status is UNKNOWN: EUIPO/TMview, WIPO, USPTO, UIBM could not be queried automatically.
- No known negative meaning. "Aqe" is awkward to type and say.

## Options

1. **Keep AQELITH (no mitigation).** Fastest; risks unknown trademark conflict and handle squatting.
2. **Keep AQELITH with mitigations (recommended).**
   - Complete the manual trademark searches (EUIPO, TMview, WIPO, USPTO, UIBM; Classes 9 and 42; phonetic/similar).
   - Privately check domain availability at a registrar; decide whether to register (user decision, user cost).
   - Prepare identity: always pronounced/spelled guidance ("AQ-eh-lith"), CLI/file extension distinct from Aqualith.
   - Consider an attorney clearance before any public launch or trademark filing.
3. **Alternatives** — not warranted now. No serious blocker was found. Reconsider only if manual searches show a conflicting Class 9/42 mark in EU, IT or US, or an active software/language product called Aqualith/Aquilith-like in the dev-tools space.

## Recommendation

Option 2: keep AQELITH as the working name, keep all assets private, and run the manual steps in `NAMING_RESEARCH.md` (Manual steps 1-8) before any public step. Re-run the automated checks on release day.

## Must not happen before approval

- No public repository, organisation, or handle claim.
- No package publication (npm, PyPI, crates.io, Homebrew, Docker Hub, etc.) or name reservation.
- No release, announcement, website, or social posts using the name.
- No domain purchase or reservation.
- No trademark claim: no (R) or TM symbol, no "registered"/"cleared" wording, no filing.
- No statement that the name is "available" or "cleared" in any document.
